Based on your results, why did Multithreading fail to make the code run faster? Why is Multiprocessing a better choice for CPU-bound tasks (like Machine Learning data augmentation) in Python?
    :Multithreading in python can't perform perfectly because the GIL(Global Intepreter Lock) inside the python architecture. 
    This prevent the os to run only one thread in the period of time. When compare with Multiprocessing that slice the one big process in to tiny small process,
    each process have their own interpreter. So the process can run individually on each core without python GILL bottleneck problem.
