1. Execution Time Comparison:
- Sequential Time: 9.59 seconds
- Multithreading Time: 9.60 seconds
- Multiprocessing Time: 8.51 seconds

2. System Observation (htop):
multithreading did not use both CPU cores fully at the same time for this CPU-bound work. only one thread could run Python code at a time, and the work could move between cores. multiprocessing used both cores at the same time, so the CPU utilization was higher.

3. Analysis (The GIL):
because the GIL lets only one thread execute Python bytecode at a time in this interpreter. adding threads did not make this CPU-bound work faster, and the thread overhead made the time almost the same as sequential.
multiprocessing uses separate processes with their own interpreters and GILs. so the OS can run them on different cores at the same time. this helps CPU-bound work like image augmentation, but starting processes and sending data between them also takes time.
